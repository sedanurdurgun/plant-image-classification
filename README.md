# Plant Image Classification
This project was developed as a 4th-year design course assignment.

The aim of the project is to classify plant images using a deep learning approach.  

A transfer learning method with ResNet50 pretrained on ImageNet is used to extract features and perform multi-class image classification.

The workflow includes data preprocessing, model training, and validation.  
The project is intended for educational and academic purposes rather than production use.

Further improvements and extensions are planned, including experimenting with different architectures, hyperparameter tuning, and dataset expansion.
